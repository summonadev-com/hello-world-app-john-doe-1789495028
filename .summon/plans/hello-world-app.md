title: Minimal Hello World App
---

Current state: the project contains only `README.md` — no scaffold, no `package.json`, no `src/`. Everything below is created from scratch.

1. Initialize the project root: create `package.json` (ESM, `"type": "module"`, npm scripts `dev`/`build`/`preview`), and install `react`, `react-dom`, `@tanstack/react-router` as dependencies plus `vite`, `@vitejs/plugin-react`, `typescript`, `@types/react`, `@types/react-dom`, `@tailwindcss/vite`, and `@tanstack/router-plugin` as dev dependencies. Outcome: `npm install` completes cleanly.

2. Create `vite.config.ts` registering, in order, the TanStack Router plugin from `@tanstack/router-plugin/vite` (configured for file-based routes in `src/routes/`), the React plugin, and the Tailwind plugin from `@tailwindcss/vite`. Add the `@/` path alias pointing at `src/`. Outcome: dev server can resolve `@/...` imports and auto-generates the route tree.

3. Create `tsconfig.json` (and `tsconfig.node.json` if needed for the Vite config) with strict mode, `moduleResolution: "bundler"`, JSX set for React, and `paths` mapping `@/*` to `src/*` so it matches the Vite alias. Outcome: no TypeScript path or JSX errors.

4. Create `index.html` at the project root with a `#root` div and a module script tag pointing to `src/main.tsx`. Set a sensible `<title>` such as "Hello World". Outcome: Vite has an entry HTML document.

5. Create `src/styles/global.css` whose first line is exactly `@import "tailwindcss";` and nothing else unless a later step requires it. Outcome: Tailwind v4 utilities are available app-wide.

6. Create `src/main.tsx` as the single entry point: import `./styles/global.css` once, import the generated route tree from `@/routeTree.gen`, create the router, and render `RouterProvider` into `#root` inside React StrictMode. Outcome: the app boots and routing is active. Note: `src/routeTree.gen.ts` is generated by the router plugin — never create or hand-edit it.

7. Create `src/routes/__root.tsx` as the app shell: a root route whose component renders a full-height, full-width wrapper with a plain neutral background and an `Outlet` centered within it. Keep it decoration-free — no nav, no header, no footer. Outcome: every route renders centered on a plain background.

8. Create `src/routes/index.tsx` for the `/` route: a static component rendering a single heading with the text "Hello World" in a large, readable weight and a neutral foreground color, plus an optional short subtext line only if it reads better. No state, no inputs, no buttons. Outcome: visiting `/` shows centered "Hello World" text.

9. Add a `.gitignore` covering `node_modules`, `dist`, and local env files. Outcome: build output and dependencies stay untracked.

10. Verification: run `npm run dev`, open the local URL, and confirm the page shows "Hello World" horizontally and vertically centered on a plain background with no console errors; then run `npm run build` and confirm it completes with no TypeScript errors. Outcome: the app builds and renders as specified.
